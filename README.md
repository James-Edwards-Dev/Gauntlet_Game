# Controls

## Main Menu

Player 1
	Change class: A or D
	Ready/Join: E
	Leave: Q

Player 2
	Change class: left arrow or right arrow
	Ready/Join: M
	Leave: N

Player 3
	Change class: F or H
	Ready/Join: Y
	Leave: R

## Game

Player 1
	Move: WASD
	Fire Projectile: E
	Ability: Q

Player 2
	Move: arrow keys
	Fire Projectile: M
	Ability: N

Player 2
	Move: TGFH
	Fire Projectile: Y
	Ability: R

## Tally Screen

Skip wait: space bar

# Helper Info

On the main menu the game will start the instant all player ready up
The game will also end the instant all players die or reach the finish

The game is playable with 1-3 players but I would recommend sticking to 1-2 player unless your just testing 3 players because of the control scheme.
